# Site Manifest Export

Generated from: https://thetabletx.com

## Key files
- `summaries/site-meta.json` - home/front-page settings and site metadata
- `summaries/all-public-urls.json` - deduped URL inventory from sitemap files
- `summaries/url-groups.json` - URL counts by first path segment
- `summaries/pages-index.json` - compact page metadata (if REST available)
- `summaries/pages-content.json` - page HTML content payloads (if REST available)
- `style/style-tokens.json` - extracted colors, font families, and media queries
- `summaries/local-plugins.txt` / `summaries/local-themes.txt` - local WP inventory

Raw API and sitemap responses are stored under `raw/` and `sitemaps/`.
